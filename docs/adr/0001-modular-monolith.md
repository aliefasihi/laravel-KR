# ADR 0001 — ماژولار مونولیت لاراول به‌جای ووکامرس

- تاریخ: ۱۴۰۵/۰۷/۲۵ (2026-10-17)
- وضعیت: پذیرفته‌شده
- نویسنده: علی فصیحی (Ali Fasihi)

## زمینه

خانه رمانتیک باید با سیستم تولید محتوا (ai-platform)، یک سوپراپ مدیریتی و n8n یکپارچه شود. ووکامرس برای این سطح از کنترل روی داده، API و URL محدودیت دارد.

## تصمیم

- بازنویسی روی Laravel 12 به‌صورت **ماژولار مونولیت** (`modules/`)، نه میکروسرویس.
- ماژول‌ها با قرارداد پوشه لود می‌شوند و با رویداد با هم ارتباط دارند.

## پیامدها

- (+) کنترل کامل روی URL، داده و API. توسعه برای یک نفر قابل نگهداری است.
- (−) درگاه پرداخت، ارسال، کوپن، فید و ایمیل‌ها باید از نو ساخته شوند.
