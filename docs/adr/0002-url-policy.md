# ADR 0002 — سیاست URL مهاجرت

- تاریخ: ۱۴۰۵/۰۷/۲۵ (2026-10-17)
- وضعیت: پذیرفته‌شده
- نویسنده: علی فصیحی (Ali Fasihi)

## تصمیم

1. URL دسته‌بندی‌ها دقیقاً حفظ می‌شود (با اسلش آخر).
2. URL محصول از نو ساخته می‌شود با الگوی `/p/{brand}-{sku}` و بدون هیچ کاراکتر فارسی.
3. مقاله‌ها با `/blog/{slug}` (ASCII) منتقل می‌شوند.
4. همه‌ی URLهای قدیمی محصول، مقاله، برگه و تصویر با **یک** ریدایرکت 301 به URL جدید می‌روند.

## چرا ریدایرکت با اینکه URL محصول «مهم نیست»؟

بدون ریدایرکت، صفحه‌های ایندکس‌شده و بک‌لینک‌ها 404 می‌شوند. هزینه‌ی ساخت جدول ریدایرکت در ایمپورت تقریباً صفر است، چون `legacy_post_id` نگه داشته می‌شود.

## پیامدها

- SKUها باید قبل از ایمپورت یکتا و دارای حروف یا عدد لاتین باشند.
- اسلاگ فارسی دسته‌ها باقی می‌ماند؛ این هزینه‌ی آگاهانه‌ی حفظ URL است.
