# Kalameh (اختیاری)

فونت فعلی سایت وردپرس Kalameh (FaNum) است که لایسنس تجاری دارد و داخل ریپو نیست.

1. فایل‌های woff2 را از پوشه‌ی فونت قالب فعلی (یا بسته‌ی خریداری‌شده) بردار.
2. با این نام‌ها همین‌جا بگذار:
   - `kalameh-regular.woff2`
   - `kalameh-medium.woff2`
   - `kalameh-bold.woff2`
   - `kalameh-black.woff2`
3. در `.env`: `KHANEH_FONT=kalameh`

تا وقتی این کار را نکنی، سایت با Vazirmatn (رایگان، داخل ریپو) نمایش داده می‌شود.
