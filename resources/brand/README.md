# Brand files — Khaneh Romantic

| File | Used for | Where it goes |
|---|---|---|
| `khaneh-romantic-logo.webp` | logo on light pages | Panel → تنظیمات فروشگاه → عمومی → «لوگو» |
| `khaneh-romantic-logo-dark.webp` | logo in dark mode / dark backgrounds | same tab → «لوگوی روشن» |
| `favicon-512.png` | browser tab icon, PWA app icon | «آیکون تب مرورگر» and تنظیمات → اپلیکیشن → «آیکون اپ» |
| `public/favicon.ico` | `/favicon.ico` (16/32/48) for crawlers and old browsers | already in place |

`source/` holds the designer's 2000×2000 transparent PNGs. The web files were made from them:
trimmed, 640 px wide; inside the emblem circle the cut-out lines were filled white so they show
on dark pages; the favicon is the emblem circle alone. Upload them through the panel's File Manager
(folder «برند») so they are in the media library too.
