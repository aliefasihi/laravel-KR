# HomeSliders — اسلایدرهای محصولات صفحه‌ی اصلی
نویسنده: علی فصیحی (Ali Fasihi)

**پنل ← بازاریابی ← اسلایدرهای صفحه اصلی**

## هر اسلایدر
| فیلد | توضیح |
|---|---|
| عنوان | دو رنگ: «کلمه‌ی رنگی» + «بقیه‌ی عنوان»، به‌اضافه‌ی کلمه‌ی لاتین کم‌رنگ پشتش (اختیاری) |
| منبع | جدیدترین‌ها، تخفیف‌دارها، **یک دسته‌بندی** (با زیردسته‌ها) یا **یک برند** |
| ترتیب | جدیدترین، بیشترین تخفیف، ارزان‌ترین، گران‌ترین |
| تعداد | ۴ تا ۴۰ (پیش‌فرض ۱۶) |
| فیلتر | فقط موجودها، فقط تخفیف‌دارها |
| طرح | ساده (کارت شیشه‌ای) یا نوار رنگی با شمارش معکوس (مثل شگفت‌انگیزها) |
| حرکت | خودکار یا دستی؛ هر چند ثانیه یک کارت |
| جا | بعد از بنر اصلی، بعد از دایره‌های دسته‌بندی، بعد از دو بنر، بعد از برندها، قبل از مقالات |

- ترتیب اسلایدرهای یک جا: کشیدن ردیف‌ها در جدول.
- اسلایدر با کمتر از ۲ محصول نمایش داده نمی‌شود.
- «کپی» یک اسلایدر را غیرفعال تکثیر می‌کند؛ برای ساخت سریع اسلایدر دسته‌های مشابه.

## رفتار در سایت
- **بی‌نهایت**: بعد از آخرین کارت، دوباره اولی می‌آید؛ از هر دو طرف.
- **خودکار**: فقط وقتی اسلایدر روی صفحه دیده می‌شود.
  - با رفتن موس، لمس یا فوکوس کیبورد می‌ایستد و بعد ادامه می‌دهد.
  - با «کاهش حرکت» سیستم‌عامل خاموش است.
- اگر همه‌ی کارت‌ها در صفحه جا شوند، اسلایدر ساده می‌ماند و حرکت نمی‌کند.
- HTML صفحه‌ی اصلی کش است. هر تغییر اسلایدر یا محصول کش را همان لحظه تازه می‌کند.

## نصب
migration دو اسلایدر صفحه‌ی اصلی فعلی را می‌سازد (شگفت‌انگیز + جدیدترین). پس روشن شدن ماژول ظاهر سایت را عوض نمی‌کند، فقط اسلایدرها بی‌نهایت و خودکار می‌شوند.

## خاموش کردن
صفحه‌ی اصلی به نوار شگفت‌انگیز و شبکه‌ی جدیدترین‌های داخلی برمی‌گردد.
