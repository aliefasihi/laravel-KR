# Appearance — حالت روشن و تاریک
نویسنده: علی فصیحی (Ali Fasihi)

- **هدر**: دکمه‌ی ماه/خورشید.
- **منوی موبایل**: سه گزینه‌ی روشن / تاریک / خودکار.
- **خودکار** از تنظیم گوشی یا کامپیوتر مشتری پیروی می‌کند و با عوض شدنش همان لحظه عوض می‌شود.
- انتخاب مشتری در مرورگر خودش می‌ماند (`localStorage`، کلید `kr-theme`).
- حالت قبل از اولین رندر صفحه انتخاب می‌شود؛ صفحه‌ی سفید چشمک نمی‌زند.

## تنظیمات
**پنل ← تنظیمات ← تنظیمات فروشگاه ← ظاهر سایت**
- حالت پیش‌فرض برای بازدیدکننده‌ی تازه: خودکار / روشن / تاریک
- نمایش یا عدم نمایش دکمه‌ی تغییر حالت

## رنگ‌ها
پالت تاریک در `resources/css/app.css` است (بلوک `:root.dark`). کلاس‌ها در هر دو حالت یکی‌اند:

| کلاس | روشن | تاریک |
|---|---|---|
| `text-navy` | سرمه‌ای | سفید مایل به یاسی |
| `bg-deep` | سرمه‌ای (دکمه‌ها) | نیلی |
| `bg-surface` | سفید (کارت‌ها، شیشه) | آبی شب |
| `border-glint` | سفید (لبه‌ی شیشه) | نور کم |

قانون برای کد تازه:
- پس‌زمینه‌ی کارت و فیلد: `bg-surface/..` (نه `bg-white`)
- دکمه یا تگ پررنگ سرمه‌ای: `bg-deep` (نه `bg-navy`)
- `bg-white/10` تا `/25` فقط روی عکس یا پنل‌های همیشه‌تیره (فوتر)
- برای استثنا: `dark:` (مثلاً `dark:bg-deep`)

## خاموش کردن
سایت همیشه روشن می‌ماند. دکمه‌ها و اسکریپت حذف می‌شوند.
