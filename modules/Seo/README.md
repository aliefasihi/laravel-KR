# Seo
ریدایرکت‌های legacy، متا، سایت‌مپ.

- جدول `redirects` با کلید `UrlPath::hash` (فرم encode/decode و ي/ی همه یک کلید)
- هر GET که به 404 برسد اول این جدول را چک می‌کند (هندلر استثنا) — پس /p/ قدیمی هم کار می‌کند
- `Redirect::point()` زنجیره‌ها را جمع می‌کند: هر URL قدیمی دقیقاً یک hop
- URLهای query وردپرس (`/?p=123`) با کلید `?p=123` ذخیره می‌شوند
- status 410 برای صفحاتی که عمداً حذف شده‌اند (تگ‌ها، آرشیوها)
