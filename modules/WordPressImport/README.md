# WordPressImport
خواندن از دیتابیس ووکامرس فعلی (اتصال read-only `wordpress`، تنظیمات `WP_DB_*` در .env).

ترتیب ایمپورت (برنامه):
1. برندها و دسته‌ها (حفظ path دقیق دسته‌ها)
2. تصاویر ← `media` با نام‌گذاری جدید
3. محصولات و ورییشن‌ها ← اسلاگ `/p/{brand}-{sku}`
4. مقاله‌ها ← اسلاگ ASCII جدید
5. بازنویسی لینک‌های داخلی و src تصاویر داخل محتوا
6. ساخت ریدایرکت برای تمام URLهای قدیمی محصول، مقاله، برگه، تصویر و `?p=`
