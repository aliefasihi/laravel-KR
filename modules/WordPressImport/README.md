# WordPressImport — انتقال کامل از ووکامرس

خواندن فقط-خواندنی از دیتابیس سایت فعلی (اتصال `wordpress`، تنظیمات `WP_*` در `.env`). هیچ چیزی در وردپرس نوشته نمی‌شود.

## اجرا
- پنل: **تنظیمات ← درون‌ریزی از وردپرس** — وضعیت اتصال، تعداد هر مرحله در وردپرس و این‌جا، انتخاب مرحله‌ها، پیش‌نمایش (dry-run)، محدودیت آزمایشی و لاگ زنده. اجرا روی صف است (queue worker لازم است).
- ترمینال (برای درون‌ریزی کامل اول بهتر است):
  ```bash
  php artisan wp:import --dry-run              # فقط شمارش
  php artisan wp:import products --limit=20    # آزمایش
  php artisan wp:import                        # همه، به ترتیب
  php artisan wp:import customers orders       # فقط این‌ها
  ```
- هر مرحله idempotent است: رکوردها با شناسه‌ی وردپرس (`legacy_*`) پیدا می‌شوند، پس اجرای دوباره به‌روز می‌کند و تکراری نمی‌سازد.

## مرحله‌ها (به همین ترتیب)
| کلید | چه می‌کند |
|---|---|
| `taxonomies` | برندها (اسلاگ ASCII، قابل تعیین در `brand_slugs`)، دسته‌ها با **path دقیق** و سئوی Rank Math/Yoast، ویژگی‌های `pa_*` و مقدارهایشان (رنگ‌ها با کد hex) |
| `products` | ساده و متغیر، ورییشن‌ها با گزینه‌ها، SKU یکتا، قیمت و حراج (تومان × ۱۰)، موجودی، دسته‌ی اصلی، تصویر شاخص و گالری، ویژگی‌ها |
| `posts` | مقاله‌ها با اسلاگ ASCII، متن، تاریخ انتشار، سئو و تصویر کاور |
| `customers` | کاربران غیر مدیر؛ موبایل از Digits / billing_phone / نام کاربری؛ نشانی‌های billing و shipping |
| `coupons` | کدهای تخفیف با سقف‌ها، تاریخ انقضا، محدودیت محصول/دسته و تعداد استفاده |
| `orders` | HPOS یا کلاسیک؛ کالاها، ارسال، کوپن، کارمزد، استرداد، یادداشت‌ها؛ مهمان‌ها با موبایل سفارش مشتری می‌شوند؛ **شماره‌ی سفارش ووکامرس حفظ می‌شود**؛ موجودی دست نمی‌خورد |
| `reviews` | نظرهای محصولات با امتیاز، «خریدار»، و پاسخ فروشگاه |
| `redirects` | ۳۰۱ برای محصولات (product base، با `%product_cat%` هم)، مقاله‌ها (ساختار پیوند یکتا)، برگه‌ها (`page_redirects`)، برندها، برچسب‌ها، `?p=` و همه‌ی سایزهای تصاویر |
| `links` | بازنویسی href/src داخل محتوای محصول، مقاله و دسته به آدرس‌های جدید؛ حذف srcset قدیمی |

تصاویر در هر مرحله‌ای که لازم شوند می‌آیند (`Support/MediaImporter`): از `WP_UPLOADS_PATH` اگر روی همین سرور است، وگرنه دانلود از سایت؛ ذخیره در `media/imported/YYYY/MM` و تطبیق با آدرس اصلی (دوباره دانلود نمی‌شود).

## تنظیمات (`config.php`)
`currency`، `brand_taxonomies`، `brand_slugs`، `default_brand`، `unmanaged_stock`، `review_default_rating`، `order_statuses` (وضعیت‌های سفارشی را این‌جا اضافه کنید)، `page_redirects`.

## بعد از درون‌ریزی
1. `ORDER_NUMBER_OFFSET` را بالاتر از بزرگ‌ترین شماره‌ی سفارش ووکامرس بگذارید (اگر نشود، شماره‌ی تکراری خودکار یک میلیون جلو می‌رود).
2. `php artisan media:optimize --queue` · `php artisan filemanager:sync --move` · `php artisan search:rebuild`
3. در **سئو ← ریدایرکت‌ها** برگه‌هایی که در لاگ «معادل ندارد» آمده‌اند را دستی بسازید.
