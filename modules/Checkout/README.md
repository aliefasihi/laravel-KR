# Checkout
سبد خرید session (شناسه‌ی ورییشن → تعداد)؛ قیمت همیشه زنده از دیتابیس خوانده می‌شود و تعداد به موجودی محدود است.

- `Support/Cart` — add / set / remove / lines / subtotal
- Livewire: `checkout.add-to-cart`، `checkout.mini-cart`، `checkout.cart-page`
- مسیر: `/cart` (noindex)

قدم بعد: آدرس و ارسال، کوپن، ثبت سفارش در ماژول Order و پرداخت در ماژول Payment.
