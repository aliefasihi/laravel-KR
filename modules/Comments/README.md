# Comments — نظرات مقاله‌ها
نویسنده: علی فصیحی (Ali Fasihi)

- زیر هر مقاله (هوک `post.after`): فهرست نظرهای تأییدشده با پاسخ‌ها (یک سطح)، «پاسخ خانه رمانتیک» متمایز، پسندیدن (یک بار برای هر بازدیدکننده)، «نظرهای بیشتر».
- فرم: نام، موبایل (اختیاری/اجباری/پنهان)، متن؛ کاربر واردشده نامش پر است. ضد ربات: فیلد مخفی + زمان + محدودیت تعداد.
- پنل ← محتوا ← **نظرات مقاله‌ها**: تب وضعیت‌ها، تأیید، رد، هرزنامه، **پاسخ به‌عنوان فروشگاه** (نظر هم تأیید می‌شود)، ویرایش، گروهی.
- تنظیمات ← نظرات مقاله‌ها: انتشار (همه پس از تأیید / مشتریان خودکار / همه خودکار)، فقط کاربران واردشده، موبایل.
- هر نظر در صندوق فرم‌ها (تب «نظر مقاله») و مخاطبان هم ثبت می‌شود.
- ایمپورتر وردپرس: مرحله‌ی `comments` نظرهای مقاله‌ها را با پاسخ‌ها و پاسخ مدیران منتقل می‌کند.
- جدول `comments` چندریختی است (`commentable`)؛ بعداً برای هر مدل دیگری هم قابل استفاده است.
