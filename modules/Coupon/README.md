# Coupon — کد تخفیف
نویسنده: علی فصیحی (Ali Fasihi)

**پنل ← بازاریابی ← کدهای تخفیف**

| گزینه | توضیح |
|---|---|
| نوع | درصدی (با سقف تخفیف) یا مبلغ ثابت |
| ارسال رایگان | می‌تواند تنها مزیت کد باشد (مبلغ صفر) یا همراه تخفیف |
| تاریخ | شروع و پایان |
| مبلغ سبد | حداقل و حداکثر |
| تعداد استفاده | کل، و برای هر مشتری |
| فقط اولین خرید | مشتری‌ای که سفارش لغونشده دارد نمی‌تواند استفاده کند |
| شماره‌های مجاز | کد شخصی برای یک یا چند موبایل |
| محدودیت محصولات | فقط این محصولات / دسته‌ها (با زیردسته‌ها) / برندها؛ به‌جز این محصولات / دسته‌ها؛ حراجی‌ها شامل نشوند |

- تخفیف فقط از کالاهای منطبق کم می‌شود؛ مثل ووکامرس.
- کد به حروف بزرگ و کوچک و فاصله حساس نیست (`yalda` = `YALDA`).
- دکمه‌ی ✨ کنار فیلد کد، کد تصادفی می‌سازد. «کپی» در جدول، کوپن را با کد تازه تکثیر می‌کند.

## در سایت
- فیلد «کد تخفیف دارید؟» در سبد خرید و تسویه‌حساب.
- خطا به زبان مشتری: منقضی، حداقل خرید، فقط اولین خرید و…

## شمارش
- با ثبت سفارش یک استفاده ثبت می‌شود.
- با لغو یا ناموفق شدن سفارش، استفاده برمی‌گردد.
