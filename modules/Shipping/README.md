# Shipping — روش‌های ارسال
نویسنده: علی فصیحی (Ali Fasihi)

**پنل ← فروش ← روش‌های ارسال**

- **هزینه**
  - هزینه‌ی پایه + هزینه‌ی هر کالای اضافه
  - هزینه‌ی جدا برای استان‌های دلخواه (مثلاً تهران ارزان‌تر)
- **رایگان بالای یک مبلغ:** مبلغ سبد **بعد از کد تخفیف** حساب می‌شود.
- **پس‌کرایه:** هزینه‌ای در سفارش نیست؛ مأمور هنگام تحویل می‌گیرد (تیپاکس، باربری).
- **محدوده:** فقط بعضی استان‌ها یا شهرها (مثلاً پیک فقط تهران). حداقل و حداکثر مبلغ سبد.
- کد تخفیف «ارسال رایگان» هزینه را صفر می‌کند.
- ترتیب نمایش با کشیدن ردیف‌ها در جدول.

با نصب، سه روش نمونه ساخته می‌شود که می‌توانی ویرایش یا خاموش کنی:
- پست پیشتاز: ۹۰٬۰۰۰ تومان، تهران ۶۰٬۰۰۰، رایگان بالای ۵ میلیون
- پیک موتوری تهران: ۱۲۰٬۰۰۰
- تیپاکس پس‌کرایه
