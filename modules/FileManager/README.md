# FileManager — فایل منیجر
نویسنده: علی فصیحی (Ali Fasihi)

## ساختار پوشه‌ها
```
محصولات                    storage/app/public/media/products
└─ گلدکیش                  …/products/goldkish
   └─ goldkish-gk7710      …/products/goldkish/goldkish-gk7710    ← یکی برای هر محصول، هم‌نام آدرس محصول
```
- پوشه‌ی محصول **خودکار** ساخته می‌شود، به محض اینکه برند و SKU معلوم باشد (حتی قبل از ذخیره‌ی محصول).
- اگر SKU یا برند عوض شود، پوشه و فایل‌ها هم جابه‌جا و هم‌نام آدرس جدید می‌شوند.
- اگر نام برند عوض شود، نام پوشه‌ی برند هم عوض می‌شود.
- نام فایل‌ها از روی پوشه ساخته می‌شود: `goldkish-gk7710-1.jpg`، `-2.webp` …
- alt و عنوان تصویر **خودکار** از نام محصول پر می‌شود. نیازی به نوشتن دستی نیست.

## در فرم محصول
1. دکمه‌ی **«آپلود / انتخاب تصاویر»**: پنجره مستقیم در پوشه‌ی همان محصول باز می‌شود.
2. فایل‌ها را بکش و رها کن یا انتخاب کن (چند فایل با هم).
3. تصاویر را **به ترتیب** کلیک کن:
   - اولی = تصویر اصلی
   - بقیه = گالری، به همان ترتیب
   - شماره‌ی کنار هر تصویر ترتیب را نشان می‌دهد.
4. بعد از انتخاب، ترتیب را با کشیدن عوض کن یا با «اصلی کن» تصویر اصلی را تغییر بده.

## صفحه‌ی فایل منیجر (`/admin/file-manager`)
- مرور پوشه‌ها و جستجو
- ساخت پوشه‌ی دستی، آپلود، تغییر نام پوشه‌ی دستی
- حذف پوشه‌ی خالی و حذف فایل بدون استفاده
- پوشه‌های سیستمی (محصولات، برندها، محصول‌ها) دستی تغییر نام نمی‌دهند. خودشان با برند/محصول هماهنگ می‌مانند.

## دستور
```bash
php artisan filemanager:sync          # پوشه برای همه‌ی محصولات موجود + اتصال تصاویر فعلی‌شان
php artisan filemanager:sync --move   # همان، و فایل‌های تصویرِ محصولات را هم به پوشه‌ی خودشان منتقل می‌کند
```
بعد از ایمپورت وردپرس یک بار `filemanager:sync --move` بزن.

## خاموش کردن
اگر ماژول خاموش باشد، فرم محصول به انتخاب‌گر ساده‌ی کتابخانه‌ی تصاویر برمی‌گردد. فایل‌ها و پوشه‌ها سر جایشان می‌مانند.
